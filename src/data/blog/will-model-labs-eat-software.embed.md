<p class="lead">基模公司会拿走标准化软件的活，可现在赚到钱的是卖芯片、内存和电的人。软件不值钱以后，值钱的是人带来的东西。</p>
<p>这是<a href="/posts/code-is-cheap-where-money-goes">《代码不值钱以后，钱流向了哪里》</a>的续篇。上一篇站在企业的角度，问企业该买什么。这一篇换到行业的角度，问两件事：以后谁来做软件，谁赚到了钱。</p>
<h2>一根会自己跳舞的针</h2>
<p>想象一家毛线厂。以前它只卖毛线，织毛衣是别人的事：有人买毛线回家自己织，有人开店织好了卖。毛线厂赚毛线的钱，毛衣店赚手艺的钱，大家相安无事。</p>
<p>现在毛线厂手里多了一根会自己跳舞的针。毛线放上去，衣服自己就串起来了。毛衣店的活，它顺手就能干。</p>
<p>基模公司就是这家毛线厂。很多人说大模型是新时代的电力、网络、钢铁，是基础设施。我觉得这个比喻不够。电厂没有去造电机、做家电，因为往上走太贵：要研发电机、建工厂、做渠道，每一步都是另一门生意。基模公司往上走就便宜多了。做软件要的是理解需求，模型本身就会写代码，云上开几千个线程跑流水线，剩下的成本主要是推理算力。</p>
<p>所以小软件公司以后的对手，不只是别的软件公司，还有手里拿着那根针的几家基模公司。</p>
<h2>LOL 免费，皮肤要钱</h2>
<p>英雄联盟本身不要钱。它靠卖皮肤、靠 IP 周边、靠赛事和广告赚钱。要是让玩家按小时付费，这个游戏多半就完了。</p>
<p>当然也有反例，魔兽世界就卖过点卡。所以更准的说法是：一样东西复制成本接近零以后，就得找别的东西来变现。LOL 找到的是皮肤、IP，还有一大群一起玩的人。</p>
<p>软件正在走到这一步。代码可以无限复制，AI 又让写代码的成本接近零，软件本身越来越不值钱。值钱的是人带来的附加价值：设计、IP、用户群，还有愿意为结果负责的人。</p>
<p>上一篇提过，有人用 AI 克隆了 Excel，523 个函数做出了 513 个，Excel 一点事没有。能复制的是代码，复制不了的是用户、格式、生态和数据。</p>
<h2>电视、信息差和入口</h2>
<p>以前很多软件赚的是信息差。拿电视来说，大部分用户不会折腾，开机看什么、装什么应用，都由厂商说了算。广告的钱、入口的钱，就这么赚到了。</p>
<p>现在知识和技术都平权了，不会折腾的人可以问 AI。靠用户不会动手赚钱的时代结束了。</p>
<p>可电视赚的钱，说到底是卖注意力的钱，这一块没有消失。AI 让内容和软件都过剩了，注意力反而更稀缺。入口只是换了地方：以前是电视开机页、手机桌面，以后是 agent 前台。用户只跟一个 agent 说话，它决定调用谁、推荐谁。谁占着这个前台，谁就是新的电视台。</p>
<p>抢前台的有两拨人：一拨是基模公司，ChatGPT、Claude、Grok 都想当这个入口；另一拨是已经握着用户的微信、苹果。小软件公司多半只能在两边之间选边站。</p>
<h2>2000 年的光纤，和今天的钱</h2>
<p>现在有个现象让我困惑：AI 应用公司大多没跑通商业模式，基模公司又说自己在赚钱。市场上的钱去哪了？</p>
<p>历史上最像的一次，是 2000 年前后的光纤泡沫。电信公司相信互联网流量会一直爆炸，借钱铺光纤。华尔街日报 2001 年的报道说，美国过去四年铺了约 900 亿美元的光纤，美林估计只有 2.6% 的容量在用。剩下的叫「暗光纤」，很多可能永远不会亮。带宽价格暴跌，Global Crossing 在 2002 年 1 月申请破产，是当时美国史上第四大破产案；WorldCom 也倒在了财务造假里。</p>
<p>后来的故事大家都知道：便宜的带宽留了下来，真正赚到钱的，是建在这些光纤上的互联网公司。</p>
<p>再看今天。基模公司说的「赚钱」，要分清是哪种赚：</p>
<ul>
<li>Anthropic 的 Dario Amodei 说：「每个模型都赚钱，但公司在亏钱。」他的意思是，单个模型拿训练成本和推理成本去比它带来的收入，是能回本的；公司整体亏，是因为同时在花更多的钱训练下一代模型。</li>
<li>OpenAI 的 Sam Altman 说：「我们的推理是赚钱的。如果不用付训练的钱，我们会是一家非常赚钱的公司。」不过据报道，同场的 COO 补了一句，说的是「已经很接近了」。</li>
</ul>
<p>两种说法都承认：公司整体还在亏。钱现在不是在被赚，是在被花。投资人和大厂的资本开支流进基模公司和云厂商，再流向芯片、内存、数据中心和电力。上一篇写过，今年一季度内存合约价一个季度涨了九成左右。真正稳定赚钱的，是卖铲子的。</p>
<p>放回毛线厂的比喻里，眼下赚钱的还不是毛线厂，是卖羊毛和织机零件的人。</p>
<p>如果照光纤的路子走，大概是三步：</p>
<table>
<tr><th>阶段</th><th>会发生什么</th></tr>
<tr><td>1. 继续加码</td><td>资本开支猛涨，直到某一轮融不到钱，或者用户的账单撑不住</td></tr>
<tr><td>2. 洗牌</td><td>模型公司合并、倒闭，算力过剩，token 价格掉下来</td></tr>
<tr><td>3. 应用层赚钱</td><td>成本终于低于收入，建在便宜算力上的公司开始赚钱</td></tr>
</table>
<p>有一点和光纤不一样。光纤铺好以后几乎没有运营成本，推理每用一次都要烧电。所以第三步的 token 价格会降，但降不到零。热钱涌入、模型降价是短期趋势，长期看未必会变成白菜价。</p>
<h2>基模公司会拿走哪些活</h2>
<p>说基模公司会「垄断」软件行业，我指的不是一家通吃，而是几家基模公司一起把小软件公司的活拿走。几家之间有竞争，一家贵了，总有别家用更低的价格来抢，所以价格不会过分高。</p>
<p>它会亲自做哪些？先看盈亏平衡：只要自己做能赚钱，它就没理由让给别人。但还要算机会成本。小软件公司做应用时，本来就在买它的 token，所以它算的是「自己做多赚的钱」和「让别人做、自己卖 token 赚的钱」差多少。</p>
<p>算下来，它会出少数标品：市场大、需求标准、做一次就能卖给所有人的东西，再加一个通用入口。长尾的活它会让出去，原因不是算力，而是销售、客服、实施、出事后的兜底，这些都按人头算成本，没法靠推理摊薄。</p>
<p>苹果把第三方应用的功能做进系统，这种事多到有个专门的词，叫「被 Sherlock」：2002 年苹果的 Sherlock 3 做进了 Watson 的大部分功能，Watson 很快卖不动，2004 年停止开发；后来 iOS 的夜览（Night Shift）也做了 f.lux 做了多年的事。AWS 在 2015 年推出托管的 Elasticsearch 服务，Elastic 在 2021 年改了开源协议，公开说就是冲着 AWS 去的，AWS 随即 fork 出 OpenSearch。但 SaaS 没有因此死掉，App Store 里的应用也没有死。平台吃掉的是薄的那一层。</p>
<p>基模公司往上走比电厂便宜，可阻力也不是零：</p>
<table>
<tr><th>阻力</th><th>说的是什么</th></tr>
<tr><td>渠道冲突</td><td>自己做应用，就是在跟买 token 的客户抢生意，客户会转去用别家模型</td></tr>
<tr><td>分发</td><td>用户的入口还在微信、钉钉、苹果这些地方</td></tr>
<tr><td>合规和准入</td><td>每个行业、每个地区的牌照，它没法一张张去拿</td></tr>
</table>
<p>所以它做通用入口和少数标品没有问题，只是速度不会像「一个月复现全部软件」那么快。</p>
<h2>小软件公司还剩什么</h2>
<p>先用上一篇的筛子：这件事，企业自己的 agent 能不能做？能做，就不是好生意。很多个性化的活不会落到专业软件公司手里，而是被企业自己的 agent 吃掉。纯粹「帮你定制一下」的活，窗口期也就一两年。</p>
<p>筛完以后，有两块我原先低估了。</p>
<p><strong>责任和监管。</strong>金融、医疗、政务、跨境这些受监管的行业，基模公司很难直接下场：它没法替每个客户承担后果，也拿不到每一张牌照，数据出境、反垄断这些规定也会限制它，而且比技术壁垒更难绕过去。软件市场会按地区和行业切成很多块，每一块里都需要一个有资质、有本地数据、出了事能签字的人。上一篇说的「兜底」和「门禁」，现在多了一个来源：法律本身。</p>
<p><strong>长尾需求。</strong>软件便宜以后，以前不值得做的需求变得值得做了：一家五个门店的火锅店，一个只有十个人的部门。上一篇说过 token 的杰文斯悖论，单价降了，总用量涨得更快；需求这边也是一样，便宜不会让市场变小，往往会让它变大。剩下的饼确实是长尾，但长尾加起来，可能比基模公司拿走的标品还大。</p>
<p>难点是长尾的单子很小，一单一单做养不活人。出路是能复用的定制：做一份行业种子，卖给很多家，再签维保。一份种子把客户带进来，维保合同把客户留下。</p>
<h2>token 会变成软件服务的计价单位吗</h2>
<p>有一种可能：token 变成「软件服务」的通货。某家模型公司卖你多少 token 的软件服务，你的需求全在它的流水线上做完。这其实就是未来的外包。一家贵了，就有小公司用更低的价格来抢，所以价格不会离谱。</p>
<p>我觉得 token 更可能是成本单位，不是售价单位。客户买的是结果，就像没人按耗电的度数买洗衣机。上一篇的结论也是往按用量、按结果收费走。</p>
<p>那怎么用好这根针，有没有秘籍？harness，也就是包在模型外面的那套工具和流程，确实会影响效果，同一个模型换个 harness，表现能差一大截。但它不是护城河。好的做法很快会被模型公司吸收进自家产品，Claude Code 就是这样。harness 有用，只是留不住钱。毛线怎么织，换不出太大的花样。</p>
<h2>衣服的设计和图案</h2>
<p>回到毛线厂。会自己跳舞的针，会把标准款毛衣都织出来。今天不同的人还要不同的衣服，毛线厂够不着的地方，价值就在衣服的设计和图案上。我想这也是以后人的工作会转去的方向。</p>
<p>我觉得是三样东西：</p>
<table>
<tr><th>剩下的价值</th><th>对应衣服的什么</th><th>为什么针替不了</th></tr>
<tr><td>能签字负责的资质</td><td>给衣服做质检、贴合格证</td><td>出了事要有人担责，牌照按行业和地区发</td></tr>
<tr><td>占住注意力的 IP 和内容</td><td>图案和品牌</td><td>大家想穿的是那个图案，就像 LOL 的皮肤</td></tr>
<tr><td>能复用的行业经验</td><td>版型</td><td>服务过很多家才知道这个行业的人穿多大码</td></tr>
</table>
<p>留个问题给你：你做的事情里，哪一部分是那根针织不出来的？</p>
